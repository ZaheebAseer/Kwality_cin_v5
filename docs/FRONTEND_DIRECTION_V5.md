# Frontend Direction V5

## Product decision
One commercial landing page, not a multi-page corporate portal.

## Primary visual hierarchy
1. Construction
2. Industrial sheds / structural work
3. Fabrication
4. Finishing / coating
5. Glass / uPVC / aluminium
6. Project proof
7. Client experience / credentials
8. Contact

## Design changes
- Replace primary service tabs with cinematic service chapters.
- Keep one isolated 3D structural viewer as an optional supporting interaction.
- Replace industry card grid with image-led market environments.
- Add a typical engagement flow rather than unsupported statistics.
- Make project proof the visual priority after services.
- Keep credentials document-led and avoid fabricated document details.
- Add a lightweight enquiry form that hands off to WhatsApp.
- Keep mobile call / WhatsApp / enquiry actions visible.
- Treat all current remote photography as representative until replaced with actual Kwality Interiors assets.

## Asset rule
The strongest future upgrade is to replace the representative images with real Kwality Interiors site and completed-work photographs, then create short image-to-video and 2.5D treatments from those real assets.
